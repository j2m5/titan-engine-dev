# Крабовидная туманность с пульсаром (хендофф)

Ветка `feat/crab-pulsar` от master 92ce2d1. Спека —
`docs/superpowers/specs/2026-09-24-crab-remnant-pulsar-design.md`, план —
`docs/superpowers/plans/2026-09-24-crab-remnant-pulsar.md` (git-ignored).

**Статус проверки.** Юнит-тесты зелёные (полный прогон), `tsc` и линт чистые.
**На GPU ничего не проверялось**: шейдер лучей в браузере не компилировался,
сцену никто не открывал; все числа стартовые, приёмка по виду за владельцем.

## 1. Что сделано

**Категория 12 `pulsar`.** Точки регистрации: `storage/database/categories.ts`,
`AllowedCategories` (`src/core/models/types.ts`), `CATEGORY_RULES.pulsar = CENTRAL`
(`validateDatabase.ts`: физика + rendering, без орбиты), `OBSERVED_TYPES`
(`SceneObserver.ts` — маркер навигации), шаблон `renderingDataTemplates`,
конфиг `src/config/pulsar.ts` (гало и LOD как у белого карлика), ветка
`RenderableFactory.createPulsar`. Тип данных `IPulsarRenderingObject`,
параметры с клампами — `src/core/renderables/Pulsar/PulsarParameters.ts`.

**Узел пульсара.** `DynamicNode` → `ApparentSizeLod` с `WhiteDwarf` и
`WhiteDwarfImpostor` (те же классы, что у категории 9; при 1e6 К цвет по
формуле упирается в бело-голубой), гало `StarInnerLayer`; поверх — объём
лучей `PulsarBeams` (ребёнок узла, не LOD), кватернион = полюс оси вращения
по строке `rotationObjects`. `beamIntensity 0` — объём не создаётся.

**Лучи-маяк** (`src/core/renderables/Pulsar/{beamKinematics,PulsarBeams,PulsarBeamsMaterial}.ts`).
Объём в `DepthVolumePass` (реестр, слой объёмов, `boundingRadius = 1.05·L`,
порядок по дальней кромке); прокси — сфера `1.05·L` BackSide; марш 24 шага в
кадре узла лучей, отрезок камера→выход из сферы, обрезка по глубине сцены
общим чанком `SceneDepth`; аддитивно, без записи глубины, потолок HDR 32.
Плотность (CPU-зеркало `beamDensity` = GLSL):
`intensity · exp(−(angle/halfAngle)²) · (1 − d/L)² · smoothstep(0, 0.02·L, d)`,
угол — к магнитной оси любого знака (два конуса). Магнитная ось:
`m = (sin tilt·cos φ, cos tilt, −sin tilt·sin φ)` в кадре, где +Y — ось
вращения; `φ = 2π·t/период + фаза`, `t` — секунды симуляции
(`getJ2000SecondsFromJD`) со свёрткой по 12 периодам, как у вращения камней:
ускорение времени крутит маяк быстрее.

**Сцена «Crab Nebula (M1)»** (сценарий 14, корень 141, светил нет, камера
`[0, 640, 640]` а.е. — куб-прокси оболочки внутри far 2 000 а.е. с запасом на отъезд).

| Актор | Категория | Строки |
|---|---|---|
| 141 Crab Nebula system | barycenter | физика 99 |
| 142 PSR B0531+21 | pulsar (12) | физика 100 (R 10 км, 1e6 К, 2.8e30 кг), вращение 31 (узел 125°, наклон 62°), rendering 113 |
| 143 Crab shell | nebula | rendering 114: `shell` 450 а.е., стенка 0.35, волокна (`ridged 1`, `worley 0.85`), две полости, палитра красно-оранжевая + зелёный secondary, запечка 192³ |
| 144 Crab wind torus | nebula | rendering 115: `torus` 115 а.е., трубка 0.35, бело-голубая, `shapeRotation [106.96, 22.617, −128.416]` |
| 145 Crab jets | nebula | rendering 116: `ellipsoid` 225 а.е., `axisRatios [0.12, 1, 0.12]`, та же `shapeRotation` |

`shapeRotation` — углы Эйлера XYZ полюсного кватерниона пульсара: поле
туманности берёт `s = R(e)ᵀ·p`, ось формы в кадре прокси = `R(e)·Y`;
совпадение с полюсом закреплено тестом (допуск 0.5°).

## 3. Расчётные числа

- Дальняя плоскость камеры 2 000 а.е. Прокси объёма туманности — куб, и его
  задние грани клипятся far по глубине вида (пиксель без фрагмента = дыра в
  объёме). Худшая ориентация — камера на диагонали куба: дистанция + size·√3.
  Оболочка 450 а.е. с 905 а.е.: 905 + 779 = 1 684; отъезд до ~1 220 а.е. без
  дыр (тест в `tests/crab`). При 700 а.е. с 990 а.е. дыры появлялись уже при
  повороте на 45° вокруг полюса (2 185 > 2 000). Альтернатива без сжатия
  сцены — поднять far в `src/config/three.ts` (лог-глубина при 4 000 а.е.
  грубеет на ~4 %), это общедвижковое решение.
- Стоимость: запечки 192³ + 128³ + 128³, три импостора 512², лучи — 24 шага
  аналитического марша на пиксель прокси-сферы (сфера в кадре целиком у
  обзора).
- Толща луча по оси: `∫(1−d/L)²` ≈ L/3 → на оси суммарная яркость
  ≈ intensity/3 · цвет (потолок 32 не достигается при 6).

## 4. Живая проверка (за владельцем)

1. Точка и гало пульсара: яркость (`exposureBias`), не пересвечивает кадр.
2. Лучи: два конуса, вращаются с периодом 4 с; тонкость (`beamHalfAngleDeg`),
   длина, яркость; при ускорении времени крутятся быстрее; камера внутри
   конуса — марш от нуля, без дыр.
3. Оболочка: рваные волокна, две дыры, красно-оранжевая с зелёным.
4. Тор и джеты — по оси пульсара, джеты выходят из полюсов, лучи сметают тор.
5. Порядок объёмов: тор/джеты/лучи внутри оболочки; при аддитивных лучах
   порядок неважен, туманности — по дальней кромке.

## 5. Вне арки

Расширение оболочки во времени, пульсация точки, засветка туманностей
лучами, честный масштаб 11 св. лет, физически верный период 33 мс.
